# Factors Associated with Time Until Adoption in Animal Shelters

This repository contains the code, report, and figures for my CSCI 3022 (Introduction to Data Science) final project at the University of Colorado Boulder.

The project investigates factors associated with shelter length of stay (LOS) for adopted dogs and cats using publicly available data from the Austin Animal Center.

## Research Questions

- **Which animal characteristics are associated with time until adoption, and
how accurately can adoption time be predicted from those characteristics?**
- Do dogs and cats have different times until adoption?
- Does age influence shelter length of stay?
- Do common breeds exhibit different adoption times?
- Does intake month affect shelter length of stay?
- How accurately can shelter length of stay be predicted using animal characteristics?

## Methods

- Exploratory Data Analysis (EDA)
- Mann–Whitney U Test
- Kruskal–Wallis Test
- Bootstrap Confidence Interval
- Multiple Linear Regression

## Repository Contents

- `notebook/` – Jupyter Notebook containing all analyses
- `report/` – Final project report
- `data/` – Original datasets and download instructions
