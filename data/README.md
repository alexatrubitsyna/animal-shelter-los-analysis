# Data

The datasets used in this project are publicly available through the Austin Animal Center Open Data Portal.

## Download

### Austin Animal Center Intakes

https://data.austintexas.gov/Health-and-Community-Services/Austin-Animal-Center-Intakes-10-01-2013-to-05-05-2/wter-evkm

Save as:

```text
data/intakes.csv
```

### Austin Animal Center Outcomes

https://data.austintexas.gov/Health-and-Community-Services/Austin-Animal-Center-Outcomes-10-01-2013-to-05-05-/9t4d-g238

Save as:

```text
data/outcomes.csv
```
